# 系列中途换对白形态：ENEMY 的零对白 → 满对白

## 主张

一个系列不必从头到尾用同一种叙事通道。ENEMY 前五部把人物台词全部拿掉，屏幕文字只剩免责声明和系统 UI 红字，故事靠动作与红字提示推进；到民国篇换成 197 条对白字幕，人物开始说话。

这个切换不是渐变而是**换挡**：零对白期最长的一部（杀意消除篇，262.5s）全片 66 格对白**一格都没有**；民国篇第一句对白出现在 63s，此后铺满 199 格里的 122 格。切换点正好落在系列换时代背景、换人物关系的节点上。

## 证据

| 作品 | 形态 | 对白格 | 画面文字格 | 出处 |
|---|---|---|---|---|
| 第一集 | 零对白 | 0 / 27 | 7（0.259） | `text05` ＋ 09 卷 §11.4 |
| 第二集 | 零对白 | 0 / 68 | 7（0.103） | 同上 |
| 第四集 | 零对白 | 0 / 28 | 4（0.143） | 同上 |
| 第五集 | 零对白 | 0 / 40 | 2（0.050） | 同上 |
| 杀意消除篇 | 零对白 | 0 / 66 | 6（0.091） | 同上 |
| 第一季大结局篇 | 过渡 | 19 / 74（0.257） | 0 | 05 卷 §二 |
| 民国篇 | 满对白 | 122 / 199（0.613） | 32（0.161） | 05 卷 §2.0–2.10 |

前五部对白为**严格的 0**，不是"接近 0"——这一点在 05 卷逐句回填之前看不出来（旧口径下它们是 0.015–0.050，因为画面文字混在 sub 里）。

## 反例与边界

- **反例/自我修正**：最初我把「前五部零对白」当作整齐切分，查 05 卷后发现大结局篇已经出现对白（52s「你你 你先别自己起床」），真正的分界是「前四部＋杀意消除篇零对白，大结局篇转型，民国篇完成」。**整齐的叙事往往是被自己的措辞逼出来的，不是数据本来的样子。**
- **边界**：n=1 系列，不能证明这是通用手法。本库另 3 个系列（小年兽、逃出大英博物馆、晒月光）都没有这种切换。
- **口径边界**：「零对白」指人物台词为 0，不等于画面无字。这五部的画面文字占比 0.050–0.259，第一集最高（每 4 格就有 1 格有红字）。所以它们不是"默片"，是"用字但不让人说话"。
- **未覆盖**：切换的**动因**未确认（是题材需要、还是平台反馈、还是制作条件变化）。档案里没有创作方陈述，不写推测。

## 可复用方式

1. **系列中段疲软时，换叙事通道比换题材省力**：把台词拿掉或加回来，观众感知到的"新"大于实际改动量。
2. **切换必须配一个硬理由**：民国篇换了时代与人物关系，零对白→满对白才不突兀。若只是"这集想说话"，会显得失控。
3. **零对白期要用可读的替代物占位**：ENEMY 用中英双语红字系统提示（WEAPONS TRANSMITTING / RANK），既交代规则又保持"无台词"的冷感。

## 饱和风险

「零对白」在动作/无限流赛道已经常见，靠它做差异化的窗口在收窄。真正的门槛不是敢不敢拿掉台词，而是**拿掉之后画面能不能扛住 60 秒以上**——扛不住的零对白就是默片事故。

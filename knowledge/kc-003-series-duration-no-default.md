# 四个系列，四种时长走势

## 主张

「系列要一集比一集长」是一个听起来合理、但数据不支持的说法。

本库 4 个系列摊开看，只有《逃出大英博物馆》是干净的严格递增（163.8 → 279.7 → 578.93，1.71× / 2.07×）。另外三个各有各的走法：晒月光第二集冲到 370s 又在第三集回落到 215s；小年兽前四集一路递减（411→403→360→381）再把大结局拉到 867s；ENEMY 在 104s 和 795s 之间来回。

真正稳定的只有一件事：**每一集都是按这一集的内容需要定的，不是按集号定的**。

## 证据

| 系列 | 集数 | 序列（s） | 走势 |
|---|---|---|---|
| 逃出大英博物馆 | 3 | 163.80 → 279.70 → 578.93 | 严格递增，1.71× / 2.07× |
| 晒月光 | 4 | 245.01 → 370.30 → 215.34 → 番外 69.24 | 冲高回落 |
| 小年兽与捉妖师 | 5 | 411.88 → 403.25 → 360.43 → 381.17 → 867.52 | 四连降后暴涨 2.28× |
| ENEMY | 7 | 104.50 → 272.00 → 110.43 → 158.97 → 262.50 → 795.50 → 296.40 | 往复波动 |

四个序列，四种形态，交集只有「首集偏短」。

## 反例与边界

- **反例（互相拆台的部分）**：拿逃出大英博物馆当样本会得出「大结局必暴涨」（578.93s 是前作的 2.07×），小年兽也符合（867.52s，2.28×）——但 ENEMY 的大结局只有 296.40s，比前作 795.50s 短了 63%。**两个正例养出来的规律，被一个反例推翻。**
- **边界**：n=4 系列、2 个账号，样本不足以否定「某种条件下逐集加长有效」，只能说它**不是普遍做法**。
- **数据边界**：ENEMY 的「杀意消除篇／民国篇／第一季大结局篇」没有集号，序列位置按建档顺序推定，可能与实际发布顺序不符。这条要在补到官方集号后复核。
- **未覆盖**：付费短剧（通常严格按时长卡点）不在本库，那类很可能真有硬性时长规范。

## 可复用方式

1. **别把「逐集加长」当默认策略**，先定这一集要讲完什么，再定时长。
2. **首集可以短**：4 个系列的首集都短于后作（104/163/245/411s 相对各自系列）。短首集降低进入成本，是四家里唯一共有的特征。
3. **大结局加长要有内容撑**：小年兽 867s 和逃出 578s 都在收束多条线；ENEMY 大结局反而短，因为它只收一条线。加长是结果不是目的。

## 饱和风险

「大结局加长」在短剧赛道已经被用成套路，观众的"要收尾了"预期被训练出来，反而削弱悬念。若加长只是把同样的信息铺开，会让完播率在最后两分钟掉得最狠。

# _会话记忆 · 过程记忆

> 知识库记"片子里有什么"，这里记"我们说过什么、定了什么"。
> **隔离**：不参与 `validate`、不进 `catalog`、不算证据。
>
> 2026-10-30 建立。

## 读的顺序

1. `project/project-tiktok-kb.md` — 长期状态（唯一权威副本）
2. `index.md` — 全部会话清单（一行一篇，行与文件一一对应）
3. `decisions.md` — 用户拍板的规则
4. `open-questions.md` — 待核项
5. 最近一篇 `sessions/*.md`

## 写的纪律

- 一次会话一篇，文件名 `YYYY-MM-DD-<slug>.md`
- 写完在 `index.md` 加一行；**行与文件必须一一对应**
- 用户拍板的规则进 `decisions.md`，不要只写在 session 里
- 待核项进 `open-questions.md`，解决了划掉不删

## 为什么隔离

过程记忆里会有"我猜""可能""先这样试试"。这些不能当证据被引用，否则库会拿猜测当结论。
